# Harness 1.24.0 (contract 1.24.0)

In-run noise: side a2. The harness's noise reference is the nightly A/A, which is up to seven days old
and runs on yesterday's machine. A difference it never saw can still be the harness's own noise on
the day. This release adds a second production stack, a2, in the same run, for the artefacts that
should not move at all. The fourth and last step of the "Policy" release. The contract changelog
entry is in [../contract.md](../contract.md#changes). A **minor** for one flag (not stable) and one
optional `report.json` field.

## What is new

- **`harness run --mode release --a2`** (compose) also starts side a2. It runs side a's four app
  images again as a compose profile, on host ports 3400 to 3404. After a and b it is captured
  **once**, with no load and no screenshots, and compared with a's run 1 for `dom`, `network`,
  `console`, `headers`, `axe` and `focus`. a2 has no signed-in reader and no persistence stub, so
  the signed-in journeys are not run on it.
- **Noise by measurement.** A difference between a and a2 is the harness's own noise on these
  images, today. An a/b difference with the same artefact and scope as one of them is listed as
  noise by measurement. `report.json` gains `inRunNoise`, and `report.html` and `report.md` say it
  on the line after "A/A consulted".
- **Reported, never judged.** No verdict, Gate, exit code, count or claim reads it. The nightly A/A
  stays the reference until 2.0, which needs ten nights of a clean A/A and a clean a-to-a2.
- `harness compare --dir` reads `a2/capture.json` when the run kept one. `harness local gate`
  takes `--a2`. `main-preview.yml` gains the dispatch input `a2`.

## What it costs, and why it is off by default

The extra cost is four more containers and one capture of the anonymous journeys. On the 30 September
Main to RC run, release mode took 8.3 minutes of a 10.4-minute job: five runs of both sides, k6
twice, the static artefacts and the stack. One more capture of one side, with no load, is about a
tenth of that, so the estimate is roughly a minute more per run. The 16 GB runner has room for four
more Node containers.

Release mode is the gate, so it is not paying that cost blind. `--a2` is off everywhere. Main to RC
runs it only when dispatched with `a2: true`, and the first such dispatch is the measurement. Turning
it on by default, in Main to RC and then in `release.yml`, is a later, one-line change.

## Upgrading

Nothing to do. A run without `--a2` is the run it was. A machine running the harness beside its own
stack has four more host ports to keep free (or move with `READER_PORT_A2` and the others, or
`--port-offset`), but only when `--a2` is given.
