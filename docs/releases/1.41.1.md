# Harness 1.41.1 (contract 1.41.0)

A forecast judged again on the same build reads the same as the first one. A **patch**: no field, verdict, Gate or exit
code moves.

## Why

On 17 Oct 2026 the Main to RC forecast of `sha-83d4ccf` was judged again at 09:04 by 1.41.0, beside its own 07:12
forecast. The A3's ledger read "#505 contributed 12; 6 unexplained": the six differences the rerun saw that the first
run did not were put between two forecasts of the same build ("no PR merged between them"), and the twelve kept the
07:12 range, read by 1.40.0, which had no CHANGELOG lines in it. The report's cause table compared the rerun with
the 07:12 forecast too, found nothing merged, and fell back to path matches (#483, #478, #481).

## What changed

- **The gap, explained.** A difference first seen in a forecast is walked back past an earlier forecast of the same
  build that already had its kind of difference (the same change, seen on more pages): no merge can lie between two
  judgements of the same code. A new kind of difference on the same build stays unexplained, as before: the stack
  moved, not the code. What each PR declares is read from the run's own
  range, the newest reading of its body, so an older forecast's range never hides a CHANGELOG line written or corrected
  since. On 17 Oct: 23 differences, claims explain 5, #505 declared 15, #505 contributed 3 (its line says (axe, dom);
  focus moved), 0 unexplained.
- **Causes and the PRs behind them.** A rerun is attributed against the last forecast of another build, so the PRs
  merged into this build are still the leads, and a declared cause is still named as declared.
