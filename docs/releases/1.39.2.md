# Harness 1.39.2 (contract 1.39.0)

The overnight run is in place by morning. A **patch**: one workflow, no field, flag or command changes.

## Why

The A3 is wanted by 07:00 Irish time. `nightly-noise.yml` had one schedule, 02:17 UTC, and GitHub starts a schedule
late or not at all when it is busy: on 15 Oct 2026 it started at 07:22 UTC, and on 16 Oct it never started, so the
A3 still showed the evening before until the A/A was started by hand.

## What changed

- `nightly-noise.yml` has two backup starts, 03:47 and 04:47 UTC. A new first job, `guard`, makes a scheduled start
  a no-op when another A/A started that UTC day and succeeded or is still running, so a night has one A/A. A start
  by hand is never skipped.
- Main to RC follows each A/A as before. After a skipped backup it finds the pair already judged and does nothing,
  unless main moved, when it judges the new commit.
