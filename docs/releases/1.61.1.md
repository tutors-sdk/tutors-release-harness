# Harness 1.61.1 (contract 1.61.0)

The calendar and LLM journey (Rule 0587) finds the calendar button by the words "View Calendar for this course" anywhere in its name. This is a **patch**: no shape or exit code changes.

## Why

Every A/A since production moved to 17.1.0 (4 Nov 2026) has been DEGRADED, and so every forecast only advisory (Gate WARN): journey `rule-0587-calendar-llm` failed on both sides at `the student presses the button starting "View Calendar"` (locator.click: Timeout 30000ms exceeded).

Mono-repo #545 (merged 30 Oct 2026, shipped in 17.1.0) renamed the calendar trigger for WCAG 2.5.3 / axe `label-content-name-mismatch`: its accessible name now starts with the text written on it and ends with the tip, `Calendar This week · Week 3, View Calendar for this course`. Up to 17.0.0 it was named `View Calendar for this course` alone. No button starts with "View Calendar" any more, on either side.

## What changed

- `traffic/journeys/steps.ts`: new step `the student presses the (button|link) containing "<words>"`, a case-insensitive substring of the accessible name. It matches the trigger on 17.0.0 and on 17.1.0 and later.
- `traffic/journeys/features/student.feature` (Rule 0587): presses the button containing "View Calendar for this course".

## Expect

The next A/A runs `rule-0587-calendar-llm` on both sides again, so it is no longer degraded and the forecast's gate is judged, not advisory.
