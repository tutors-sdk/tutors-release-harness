# Harness 1.17.0 (contract 1.17.0)

The overnight readiness page. Main to RC already judges main against production every night and
keeps the forecast; what was missing was a page to read it night by night and pick a commit
from. `readiness.html` is that page: one row per night for the last ten, newest on top. The
third step of the "Page" release. The contract changelog entry is in
[../contract.md](../contract.md#changes). A **minor** release, because it adds a command: no
verdict, exit code or `report.json` field changes.

## What is new

- **`harness readiness --site <dir>`** writes `readiness.html` and `readiness.json` into the
  site. Each night that kept a forecast shows the commit judged (the full sha, linked in the
  monorepo, and the four image digests under "last night"), production beside it, the Gate, the
  unclaimed count, **new / gone since the previous forecast** (the `delta` of 1.16.1) and links
  to the kept report, its migration and upgrade rehearsals (kept since 1.16.0, with their
  verdicts) and the run. Two runs on one night: the newest leads, the other follows it.
- **A quiet night is a row too.** From the workflow history the A3 already fetches
  (`github.json`): **unchanged since sha-…** in grey with the Gate it repeats, when Main to RC
  ran and skipped a pair it had already judged; **not judged** when it failed; **did not run**;
  **not yet** tonight. Without the history such a night is **not known**, never guessed.
- **Production moving draws a rule** across the strip: the delta starts again, and two
  baselines are never read as one run of nights.
- **No band on the row.** The review floor caps the score at 74 while the release range holds
  unreviewed PRs, so the band would be Red on any night the Gate passes. The Gate decides.
- **The site**: `pages.yml` builds it after the A3 (a failure is a warning), and the top of
  `site/index.html` links it. `readiness.schema.json` describes `readiness.json`.

## Upgrading

Nothing to do. Forecasts kept before 1.16.1 show "not counted" for new / gone, and before
1.16.0 no rehearsal links. To build the page locally from a site directory:
`pnpm harness readiness --site _site`.
