# Harness 1.37.0 (contract 1.37.0)

The A3 says what it compares and explains the gap. A **minor**: a new `a3.json` field, `gap`, and a
new block on the A3 page. No `report.json` field, verdict, Gate input, exit code, claims key, flag,
mask or workflow changes.

## Why

Leigh, 15 Oct 2026, on the A3: it does not state the comparison; it does not show clearly what is
claimed or which PRs are behind a difference; "402 unclaimed doesn't make sense to me when it could be
attributed to one thing"; and "if the gap is X differences I want to know that A, B and C contributed
towards it and it leaves Y as the unexplained gap."

## What changed

- **What is compared, first.** Under the title: "This sheet compares main at sha-51e5dcb (Main to RC
  forecast) against production 16.2.2, run 2026-10-15 07:53 UTC." The first fact line repeats it.
- **The gap, explained** (`src/changes/explain.ts`). Every failing difference of the run lands in one
  row, and the rows add up to the total:
  - **claimed**: one row per claim;
  - **contributed by a PR**: read from the kept forecasts beside the same production, the night the
    difference first appeared, narrowed to the PRs merged that night whose files touch what changed.
    One PR that matched more files than the rest leads its row ("#466 most likely"); otherwise the
    night's PRs are one row ("one of #a, #b"). Nothing is split between PRs by guesswork;
  - **unexplained**: it appeared with no PR merged in between, or more than eight PRs could have made
    it (the best file matches are listed as suspects, not counted).
  On 15 Oct's forecast: 1110 differences; claims explain 698; #466 (SvelteKit 3) most likely
  contributed 195, 169 of them the SBOM's added packages; #470 24; #438 13; 9 more PR groups 32;
  148 unexplained, 139 of them already there on 27 Sep, the oldest forecast kept.
- When the Gate and the kept verdict differ, the block says why (a FAIL kept as WARN because the
  A/A did not count).

It is a lead to read and never changes the Gate, the score, a verdict or an exit code.
