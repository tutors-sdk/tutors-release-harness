# Harness 1.14.0 (contract 1.14.0)

The A3 Aggregator. The harness already kept the pieces of a release's story in different places:
the Gate and the score in `confidence.json`, the PRs in `changes.json`, the line stops in the
workflow runs, the noise history, the scoreboard and the kaizen register. 1.14.0 puts them on
one page, the way a Lean team puts a problem on one A3 sheet, and makes that page the centre of
the reports site. Nothing in it is a break: no verdict or exit code changes. It is a **minor**
release because it adds a command and three flags. The contract changelog entry is in
[../contract.md](../contract.md#changes); the Lean view is [docs/lean.md](../lean.md).

## What is new

- **`harness a3 --site <dir> [--kaizen kaizen] [--fetch-github]`** writes `a3.html`, `a3.json`
  and `github.json`. The page leads with the final scoring (Gate, RCS, band, dimensions), then:
  1. **Background**: what is being released and from where.
  2. **Current condition**: a value stream map (merge, image build, accessibility audit,
     forecast, release gate, deploy, verify) with waits, inventory, lead time and an andon on
     each stage that stopped; four Paretos (unclaimed hunks, line stops, confidence points lost,
     change-risk points) with the vital few cut out.
  3. **Goal**, 4. **Root cause** (questions answered from the data, each linked to its 5 Whys),
     5. **Countermeasures**, 6. **Plan**, 7. **Follow-up** (from the register), then the 5 Whys
     themselves and the Lean terms the page uses.
- **Not measured, never guessed.** A file or GitHub call the A3 could not read is named, and the
  part that needed it says so.
- **The site**: `pages.yml` runs it on every build (a failure is a warning, not a broken site)
  and `site/index.html` shows the A3 section with a link to the full page.
- **The first three 5 Whys** in `kaizen/`: the Gate FAIL on the newest Main to RC forecast (893
  unclaimed hunks, 696 of them one removed npm toolchain), the 16.2.2 rollback (production is
  not the gated image), and a fixed-on-B accessibility finding the glance called unclaimed.
- **Claim guidance**: `claims/README.md` shows how one brace-list SBOM claim covers a tool
  removed from every image.

## Upgrading

Nothing to do. To build an A3 locally from a site directory:
`pnpm harness a3 --site _site --kaizen kaizen`.
