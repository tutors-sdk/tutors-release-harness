# Harness 1.39.1 (contract 1.39.0)

A journey is flagged on its control chart by main's median, not by one run. A harness-only **patch**: no field,
flag or workflow changes.

## Why

The first Main to RC forecast on 1.39.0 (15 Oct 2026, 21:21) flagged student-signs-in: one run of five on main,
6610ms, was just over production's UCL of 6344ms. It was run 1, the cold start, which is slow on both sides
(production 6480ms then about 4000ms; main 6610ms then about 3900ms). Main's median, 3934ms, sits inside the limits,
so the flag pointed at the same special cause production has and not at a change in main.

## What changed

- `controlState(journey)` (`src/compare/timing-control.ts`): main's median above the UCL or below the LCL flags the
  journey; single runs outside are still reported in the reading ("1 of 5 single runs outside").
- The A3's Speed light reads the same state, so it agrees with "Timing on control charts", which already judged
  the median.
