# Harness 1.49.0 (contract 1.49.0)

Pixelmatch 8, which scores screenshot differences in OKLab. A **minor**.

## Why

Dependabot's #145 moves `pixelmatch` from 7.2.0 to 8.0.0. Its API and the scale of `threshold` are unchanged, but it compares colours in OKLab with the HyAB distance instead of YIQ, so the number of differing pixels for the same two screenshots changes. A **minor** rather than a patch for that reason: a `screenshot` difference judged by 1.49.0 is not comparable with one judged by 1.48.x.

## What changed

- `pixelmatch` ^8.0.0 in `package.json` and `pnpm-lock.yaml`. No harness code changes; `screenshot.pixelThreshold` keeps its value.
- The mutants and the A/A on this PR show the screenshot engine still catches the planted defects and stays quiet on identical stacks.
