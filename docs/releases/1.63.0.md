# Harness 1.63.0 (contract 1.63.0)

The harness now watches `tutors validate`, which since mono-repo #591 decides whether a lecturer's course deploys. This
is a **minor** release: a new command, `harness validate deploy|forecast` (not stable), the validate corpus, and the
workflow `validate-forecast.yml` with its artifact `validate-forecast`.

## Why

Leigh (11 Nov 2026): "For the release harness we now have a validate CLI command in mono-repo, is that something we can
take advantage of?" Since #591 the standard netlify.toml runs `jsr:@tutors/tutors-create@^5.4.0 validate` before the
generator. That opens two ways a release breaks lecturers that no image the harness compares would show: a build command
JSR cannot satisfy, and a rule change that stops courses deploying.

## What changed

- `harness validate deploy --candidate <mono-repo checkout>`: every `jsr:` specifier in the template's build command
  must resolve on JSR, and the tutors-create run as `validate` must export it. Exit 1 when a course built from the
  template would fail its deploy.
- `harness validate forecast --candidate <checkout>`: main's validate, run from source, beside the published one (the
  template's tutors-create as JSR resolves it now), over `fixtures/validate-corpus/courses.yaml`. That file holds five
  real course sources pinned by commit: tutors-reference-course, python, and Leigh's three samples. Every difference is
  explained by rule, and newly stopped courses are named. Advisory, unless `--strict`.
- `validate-forecast.yml`: daily at 05:37 UTC, on demand (any mono-repo ref), and on pull requests that change it. The
  deploy check fails a scheduled or dispatched run. On a pull request it is reported only, since the PR changes the
  harness, not JSR.

## First run (11 Nov 2026)

- **deploy: FAIL.** JSR's newest `@tutors/tutors-create` is 5.3.0, which has no `validate`, and nothing is in `^5.4.0`.
  A course made from main's templates fails its deploy until 5.4.0 and `@tutors/course-rules` are published. The daily
  run stays red until then.
- **forecast:** production can't run validate yet, so main's findings stand alone. Four of the five courses would be
  stopped from deploying: reference-course (2 × V004), web-dev-2-2022 (V004), mobile-app-dev-oth (V002) and
  agile-soft-dev-2013 (4 × V002).

`report.json`, a release candidate's Gate and every existing exit code are unchanged.
