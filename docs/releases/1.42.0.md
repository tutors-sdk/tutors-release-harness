# Harness 1.42.0 (contract 1.42.0)

PASS, explained. A Main to RC forecast whose only reason to fail is unclaimed differences, every one of them declared
in the CHANGELOG line of the PR that made it, passes, and says why. A **minor**: the forecast's Gate moves.

## Why

On 17 Oct 2026, with tutors-mono-repo#505's CHANGELOG line corrected to `(dom, focus)`, every difference of the forecast
of `sha-83d4ccf` was explained: claims explain 5, #505 declared 18, 0 unexplained. The Gate still said FAIL, because
1.41 never let a declaration change the verdict. Leigh: "It should change the verdict though if its explainable. So
pass with explanation makes sense."

## What changed

- **The Gate.** On a forecast (side b is `sha-<short>`), when the run failed only on unclaimed differences and the
  ledger (src/changes/explain.ts) puts every one of them under "declared by its PR", the kept `confidence.json` says
  `PASS`, its note "PASS, explained: all 18 differences no claim covers yet are declared in the CHANGELOG line of the
  PR that made them (#505: 18). Nothing is owed on main; the release author pastes the claims from those lines when
  the release is cut." The index entry, the report's lead and the A3 read it. The A3 reads a forecast kept before
  1.42.0 the same way.
- **Unchanged.** One difference nobody declared, any other reason to fail (a rehearsal, the A/A), or a release
  candidate keeps the FAIL. The run's own `report.json` keeps its verdict, and `harness run` its exit code: the
  explanation is a reading of the run, never a rewrite of it.
