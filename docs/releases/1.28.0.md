# Harness 1.28.0 (contract 1.28.0)

The replay set: runway improvement G, after Diffy. The contract changelog entry is in
[../contract.md](../contract.md#changes). A **minor**, for a new journey set, journey and artefact
name. **The verdict never moves**: the check ships informing.

## Why

Six journeys reach the pages someone wrote a journey for. A route nobody walks is never compared.
Diffy's answer is to replay requests and compare only the responses, which needs no journey.

## What is new

- **`replay`**, a fourth journey set. Its one journey, `replay-course-urls`, opens a fixed list of
  URLs (`traffic/replay/urls.ts`) directly on both sides. It runs once and takes no screenshot, axe
  scan or focus walk. The list starts with the pinned fixture course, on pages no other journey
  opens: the second topic, a talk, both notes, a step of the second lab, and a topic that does not
  exist. That list is the decision the runway asked for, "which course URLs are fixed enough to
  replay". Add a URL only when it is anonymous, read-only and fixed.
- **Status, headers and network only.** The `replay` artefact compares those pages with network's
  and headers' own words. No other engine sees them, so they add no DOM, screenshot, console,
  timing or persistence hunks, and they do not move the glance or the scoreboard's journey counts.
- **Informing, with no date.** The runway puts G after 2.0, so it is the last check to be promoted.
- **A planted mutant**, `replay-header`, drops `X-Content-Type-Options` on `/note/` pages, which
  only the replay set opens on the fixture course. No blocking engine sees it: the run passes and
  only `replay` reports it. Sixteen mutants.
- `--set` takes `replay`, and the default runs all four sets.
