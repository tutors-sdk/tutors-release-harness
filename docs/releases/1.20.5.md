# Harness 1.20.5 (contract 1.20.5)

A report fits a phone. A kept forecast read at 375px was 1,131px wide: the provenance table, the
differences, the image artefacts, the score's dimensions and the change risk per PR each pushed the
page sideways, and a long claim scope in a glance line did too. The contract changelog entry is in
[../contract.md](../contract.md#changes). A **patch**: no command, flag, `report.json` or index
field, verdict, Gate or exit code changes.

## What is new

- **Tables scroll inside their own box under 640px**, and a long name in a sentence breaks where it
  must, so the page itself never scrolls sideways. At 1400px nothing changes.
- **In the lead's style too** (`NARROW_CSS` in `src/report/narrow.ts`, part of `LEAD_CSS`): a kept
  report rendered by an older harness, such as a rehearsal, gets it when it is kept.

## Upgrading

Nothing to do. Reports already on the `main-preview` branch keep their old style until they are
kept again.
