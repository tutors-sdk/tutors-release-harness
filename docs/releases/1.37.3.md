# Harness 1.37.3 (contract 1.37.0)

The reference course journey reads the note again. A harness-only **patch**: no input, output field,
verdict, exit code, claims key, flag, workflow or mask changes, so the contract stays at 1.37.0.

## Why

Since 9 Oct 2026 every nightly A/A was DEGRADED and did not count: `reference-course-reads` failed on
both sides, 5 of 5 runs, with `strict mode violation: getByRole('article') resolved to 2 elements`.
Mono-repo #400 (8 Oct) put the open learning object's card, an `<article>`, in the course navigation
beside the page, so the note page has two. With the A/A degraded, every release run (17.0.0-rc.1
included) could only WARN, never PASS or FAIL.

## What changed

- The journey waits for the article inside `main` on the note page and the lab page, the page's own
  content, not the navigation's card. Checked against a page shaped like main's shell: the old locator
  reproduces the strict mode violation, the new one finds the note.
