# Harness 1.57.0 (contract 1.57.0)

Mutants for the silent engines. A **minor**. Part of the harness hardening plan (production-readiness additions, tranche 1, item B5).

## Why

Eight engines had no planted fault: screenshot, metrics, logs, runtime, startup, slo, realtime and bus. The self-test could not say whether any of them would catch a regression, and the 2.0 promotion rule (an engine blocks once its mutant has been caught on the soak) could never fire for them. B5 is what lets any later engine be promoted.

## What changed

Seven new edge mutants, each planted by `mutants/wrap.mjs` in front of the production reader:

| Mutant | Plants | Must be caught by |
| --- | --- | --- |
| `screenshot-shift` | a stylesheet that moves every page down 2 px | `screenshot` |
| `metric-dropped` | `http_requests_in_flight` gone from `/metrics` | `metrics` |
| `log-level-flood` | a JSON warning for every page served | `logs` |
| `writes-outside-tmp` | a cache written into the app's directory at boot, refused by the read-only root filesystem (`EROFS` logged) | `runtime` |
| `slow-boot` | 3 s before the reader listens, on every start | `startup` |
| `slo-5xx-burst` | three calls per page to an endpoint that answers 500, counted in the reader's request SLI | `slo` (informing) |
| `realtime-chatty` | two more Realtime broadcasts per page view | `realtime` (informing) |

- `slow-boot` sets `startupRestarts: 5` in `mutants.yaml`, a new optional field: its run restarts every app five times a side, the only run of the self-test that samples startup.
- `bus` waits: there is no bus yet to plant a fault on.
- The wrapper now drops `transfer-encoding` when it rewrites a body and sets its length. A streamed answer carrying both headers is not HTTP/1.1.
- `tests/mutant-wrap.test.ts` runs the real wrapper in front of a stand-in app and checks each fault is planted.

## What to expect

The weekly self-test builds twenty-four images instead of seventeen, which adds about twenty minutes. If one of the seven escapes, its engine cannot do what it claims, and that is the finding. The readiness page counts the new mutants.

## Level

No engine's level changes. No verdict, Gate, score or exit code moves.
