# Slide sources

The course's talks are written here as [Marp](https://marp.app) markdown, one deck per topic, with the shared theme in `harness.css`. Tutors shows a talk as a PDF, so `build.sh` renders each deck into its talk folder (and `cover.md` into `course.png`). Edit a deck, run `./build.sh`, and commit the markdown and the PDF together.

This folder has no Tutors prefix (`topic-`, `talk-`, `book-`, …), so the Tutors generator does not publish it.
